## Sobre o Repositório

Este repositório centraliza os projetos práticos, dashboards analíticos e resoluções de desafios de código desenvolvidos ao longo das formações e bootcamps da **[Digital Innovation One (DIO)](https://www.dio.me/)**. 

O objetivo deste portfólio é documentar a evolução técnica em **Análise de Dados, Business Intelligence e Lógica de Programação**, aplicando boas práticas de modelagem de dados, construção de indicadores (KPIs), visualização executiva e desenvolvimento de algoritmos em **Microsoft Excel**, **Python** e **JavaScript**.

## Formação Análise de Dados com Excel e IA

Projetos práticos voltados para estruturação de bases de dados, modelagem financeira, automação com fórmulas avançadas e criação de painéis interativos (Dashboards) com foco em tomada de decisão e experiência do usuário (UI/UX).

| Projeto | Foco e Recursos Principais | Documentação | Arquivo `.xlsx` |
| :--- | :--- | :---: | :---: |
| **Dashboard de Vendas do Xbox** | Análise de faturamento de assinaturas (*Game Pass*, *EA Play*, *Minecraft*), Tabelas e Gráficos Dinâmicos, *Slicers* (Anual, Mensal, Trimestral) e UI customizada. | [📖 Ver README](<./Formação Análise de Dados com Excel e IA/Dashboard de Vendas do Xbox com Excel/README.md>) | [📥 Planilha](<./Formação Análise de Dados com Excel e IA/Dashboard de Vendas do Xbox com Excel/Dashboard de Vendas do Xbox com Excel.xlsx>) |
| **Organizador de Imposto de Renda** | Controle de declarante, informes de rendimentos e notas dedutíveis com navegação estruturada, validação de dados (*Data Validation*) e funções de busca. | [📖 Ver README](<./Formação Análise de Dados com Excel e IA/Organizador de Declaração de Imposto de Renda/README.md>) | [📥 Planilha](<./Formação Análise de Dados com Excel e IA/Organizador de Declaração de Imposto de Renda/Organizador de Declaração de Imposto de Renda.xlsx>) |
| **Simulador de Investimentos FII** | Projeção patrimonial com juros compostos (Valor Futuro), estimativa de *Dividend Yield* e alocação dinâmica por perfil de risco (Conservador, Moderado, Agressivo). | [📖 Ver README](<./Formação Análise de Dados com Excel e IA/Simulador Investimentos FII/README.md>) | [📥 Planilha](<./Formação Análise de Dados com Excel e IA/Simulador Investimentos FII/Project_DIO_Invest.xlsx>) |
