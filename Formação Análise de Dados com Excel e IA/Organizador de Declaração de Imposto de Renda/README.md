# Organizador de Declaração de Imposto de Renda

## 📊 Descrição do Projeto
Este projeto é uma ferramenta desenvolvida inteiramente no Microsoft Excel, criada como solução para o desafio da Formação em Análise de Dados com Excel e IA da **DIO**. O objetivo principal é facilitar a organização e o controle das informações essenciais para a Declaração de Imposto de Renda, garantindo um preenchimento eficiente por meio de validações automáticas e navegação estruturada.

## 🛠️ Estrutura e Funcionalidades
A planilha foi construída com foco em usabilidade, contendo menus de navegação e divisões lógicas:
* **Titular:** Área para organização dos dados do declarante.
* **Informes:** Controle e lançamento dos rendimentos e fontes pagadoras.
* **Notas:** Registro de despesas, recibos e notas fiscais dedutíveis.
* **Tabela (Bancos):** Base de apoio para alimentar as listas suspensas e validações de dados (Data Validation).

## 🚀 Recursos Utilizados
* **Microsoft Excel**
* Validação de Dados para padronização de entradas
* Fórmulas lógicas e de busca
* Design de interface (UI) focado na experiência do usuário
